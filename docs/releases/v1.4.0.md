# Release v1.4.0 - 用户私有测试历史与连接管理

## 新增

- 普通用户可保存、编辑和删除自己的 API 连接；API Key 使用 AES-256-GCM 加密保存，页面与接口仅显示掩码，不提供读取明文接口。
- 在线文本、中文 HTML 动画和英文 SVG 测试自动保存私有历史；支持筛选、详情、源码下载、隔离预览和再次测试。每次调用仅发送本次提示词，不自动附带历史回复。
- 管理端增加用户连接和测试记录页面，可审查结果、删除记录和禁用连接；管理接口不返回密钥，也不提供代用户调用入口。
- 私有历史默认保留 30 天，后台可配置 1–365 天；连接保留到用户主动删除，私有结果不会进入公开作品墙。

## 优化

- 响应工作区支持作品预览、完整回复和提取源码切换，增加复制、下载、自动换行、流式跟随与分组指标；成功作品默认展示预览。
- 拆分保存的连接、测试历史和本次记录入口；个人账号采用紧凑资料卡、独立快捷入口和适配手机的密码表单。
- Anthropic 参数按 Messages 协议构造；完善推理强度与 Thinking 组合校验，不根据模型名称猜测参数，也不在失败后自动换协议重试。
- 生成回复含多个代码块或重新开始的完整文档时，按完整代码边界提取作品，保留原始回复供核查。

## 修复

- 保存连接的获取模型与生成请求必须携带已确认的修订号；连接已变更时明确拒绝，避免使用未确认的新配置调用。
- 同一用户的客户端请求 ID 防止重复生成；最终保存失败不再伪称已保存，取消和进程中断保留已成功写入的部分内容。
- 模板版本根据实际提示词及本人历史核验，防止为修改后的提示词错误标注标准模板版本。
- 重复连接编辑返回明确冲突，保留原连接；后台、用户和公开接口分别处理访问权限。
- 单个未发送任务的租约过期或冲突不再直接判定为整个 Worker 租约丢失；请求仍不会发出，真正的进程租约丢失仍停止旧执行器。

## 安装与升级兼容

- Windows amd64 选择完整 ZIP；Linux amd64／arm64 选择对应完整 tar.gz。完整包含服务端、launcher、脚本、示例配置与文档，运行时无需 Node.js。
- 已完整部署协议 2、usage_guard 1 的 v1.3.x 实例可在线检查本版。v1.2.2 及更早版本先使用完整包同时更新程序和 launcher。
- 升级前备份数据库与 master.key；启动时支持 Schema 1／2 向前迁移为 Schema 3，原账号、分组、任务和作品保留。
- Launcher 协议仍为 2，usage_guard 为 1；Manifest 标注 database_schema=3、min_database_schema=1。
- 升级失败可由 launcher 恢复升级前快照。升级成功后，Schema 3 数据不可仅回滚到只支持 Schema 2 的旧程序；恢复旧快照会回退之后的数据，需单独操作。
- 11 个发布附件包含 6 个裸程序、3 个完整包、manifest.json 和 SHA256SUMS。发布包不包含运行数据、数据库、master.key、日志、本地配置、Token 或真实 API Key。

## 验证

- 本地全量 Go 测试与 vet、104 项前端测试、类型检查与构建、9 项打包测试、Windows 真实二进制升级恢复检查通过。远端发布流水线另执行 Windows／Linux amd64 回归与 Linux race 检查。
- 修复后另行完成连续 5 分钟、100 个模型、5 个分组的本地持续测试：1,589 次模拟请求、2 次 Worker 重启、200 个模型／模板组合覆盖，未发现并发越限和预设故障之外的错误，SQLite 完整性为 ok；没有真实上游调用。该结果不替代连续 24 小时验证。
- 用户私有历史已有 Chat、Responses 文本及中英文作品真实调用记录；本轮发布检查使用本地夹具及已有只读记录，没有追加付费模型调用。
- 草稿附件上传后重新下载，对照大小和 SHA-256 核验，校验完整后才设为正式最新版。

## 已知限制

- 旧版 24 小时连续负载验证曾分别在约 8 小时和 3 小时后中断／失败。本次修复已覆盖单任务冲突被放大全局故障的路径，原长测故障的全部触发条件及修复后的连续 24 小时运行仍未验证。
- Linux arm64 提供交叉编译包，尚未在 arm64 主机运行验证。
- 各中转平台的模型、用量、缓存和参数支持由上游决定；模型列表成功、HTTP 200 或返回的模型名称不等于完整生成成功或模型身份认证。
- 上游已发出的请求在取消后是否停止计费由上游决定；突然断电只能保留最后一次成功写入的内容。
