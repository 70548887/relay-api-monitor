# Release v1.3.1 - 独立账户、分组测试与稳定性修复

## 新功能

- 用户端与管理端独立布局、登录和会话；监控、作品公开，在线测试需普通用户登录。后台分别管理普通用户和管理员。
- 分组列表支持选择模型、中文 HTML 或英文 SVG 模板执行一次测试；定时测试可独立设置模型、模板和间隔。
- 分组计划接管定时创作后，模型页面明确提示实际计划来源，双模板按顺序执行，互斥时保留另一模板的待执行周期。
- 按协议支持完整推理参数；实际请求记录独立上下文与上游提供的缓存用量。历史作品不会作为下一次生成的上下文。

## 修复

- 可选加密 DNS 回退处理代理 Fake-IP；公共地址校验与固定连接继续生效。修复临时断线和单地址族失败导致的整体失败；仅按 TTL 缓存有效解析结果。
- GitHub 只读请求有限重试、中文网络诊断、较旧发布版提示；模型生成不自动重发。
- 任务入队和发送前核对模型、分组、平台状态及配置；健康检测不再继承创作输出和超时。
- 补齐实际 Worker 状态、动态耗时和离线提示；对齐设置页与后端接受范围。
- 密码修改核对已验证的旧哈希，防止并发重置被过期请求覆盖。

## 安装与迁移

- 首次安装使用对应平台的完整压缩包。Windows 运行 `scripts/start.ps1`；Linux 参考 `deploy/README.md`。
- v1.2.2 及更早版本必须先备份数据库和 master.key，再手动部署完整包，同时更新程序、launcher 和脚本。保留原数据目录及本地配置。
- 已完整部署本地 v1.3.0 的实例可验证在线更新至本版；launcher 协议为 2、usage_guard 为 1，数据库 schema 为 2，兼容 schema 1 向前迁移。
- 公开包不含数据库、master.key、真实 Key、账号密码、日志或填写后的 config.yaml；没有固定默认账号。

## 验证

- Go 全套测试、go vet、前端 94 项测试、34 项 Chrome 回归，以及隔离真实二进制升级与故障恢复测试通过。
- 长时间测试使用显式开启的 `TestLongRunningWorkerStability`，覆盖 100 个模型、5 个分组、限流、断流、超时、取消和 Worker 重启；实际持续时间与结果记录在 `docs/VALIDATION.md`。
- GitHub 升级需要通过真实 Release 下载、校验和隔离安装后再记录为已验证，单独构建通过不代表此链路已通过。

## 已知限制

- 发布二进制为 Windows amd64、Linux amd64/arm64；Linux arm64 仅交叉编译，未在 arm64 主机实测。
- 有限时长的稳定性测试不能替代生产环境数天或数周运行验证。
- 上游缓存由提供方管理；独立上下文不等于提供方禁用缓存。缓存用量未提供时无法判断。
