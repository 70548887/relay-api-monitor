# Release v1.3.2 - 修复慢速升级下载超时并扩展稳定性验证

## 修复

- 程序附件下载不再共用 GitHub 元信息请求的 2 分钟总超时，改为独立且可取消的 15 分钟上限；原有操作期限更短时仍服从操作期限。
- 元信息继续使用短超时；下载客户端复制原有网络配置，保留 GitHub 域名、重定向、认证脱敏、大小限制与 SHA-256 校验。
- 中断或超时不会留下可安装的半成品，不自动重发已开始的模型生成。

## 验证

- 补充下载超过元信息预算、元信息独立超时、取消清理及不可信重定向回归。
- 新增显式开启的真实 GitHub 慢速下载验证，实际下载 Release 字节并限速读取，验证超过 2 分钟后仍完成大小和 SHA-256 校验；实际结果见 `docs/VALIDATION.md`。
- 扩展持续负载测试至公开监控／作品 HTTP 查询、全部历史失败检查及完整模型／模板覆盖；24 小时运行必须结束后才记录为通过。

## 安装与升级

- v1.3.0／v1.3.1 完整安装的实例可检查本版并在线升级。旧版更新器本身仍受其原有 2 分钟下载限制；若旧版线路过慢，应切换较快线路或使用已校验的完整包迁移，安装本版后后续附件下载使用新预算。
- v1.2.2 及更早版本仍需先部署完整包，同时更新程序和 launcher。
- launcher 协议 2、usage_guard 1、数据库 schema 2 不变；回滚仍要求旧程序兼容当前数据库并保留升级后新数据。
- Release 不含运行数据、数据库、master.key、本地配置或凭据。

## 限制

- 15 分钟仍是有界超时，不保证断网或任意慢速线路均能完成下载。
- 有限时长测试不代替所有生产环境的长期观察；Linux arm64 仍仅交叉编译。
