# Release v1.4.1 - 单模型调度、自适应后台与 Docker 部署

## 发布信息

- 正式稳定版；Tag `v1.4.1`，版本来源为根目录 `VERSION`。
- 支持 Windows amd64、Linux amd64 和 Linux arm64。
- 兼容 Schema 3、launcher 协议 2、usage_guard 1，与 v1.4.0 保持一致。

## 新增

- Docker 多阶段源码构建、Linux 完整包容器构建、Compose 配置与中文宝塔部署说明。数据库、加密主密钥及历史保存到持久化数据卷。
- 显式 `server.public_url` / `RELAYLAB_PUBLIC_URL`，用于 HTTPS 反向代理后的同源校验和 Secure Cookie，保留登录和 CSRF 验证。
- 平台官网地址、关联分组数量、后台模型与模板选择及单次推理参数覆盖。

## 优化

- 分组编辑按基础连接、模型与开关、推理参数、高级设置分栏；弹窗按窗口宽高和内容居中适配，保留固定操作栏及完整摘要。
- 可保存并获取当前分组的模型目录，完善监控、作品对比、历史切换与手机界面。
- 前后台统一显示北京时间预计触发时间、倒计时、排队与等待原因。预计触发后可能排队。

## 修复

- 健康检测与定时创作仅执行分组指定的一个模型，默认精确匹配 `gpt-6.1-sol`；不存在时等待同步或明确选择，不使用目录首项代替。
- 同步目录不扩大自动调用范围。保存明确选择时可将旧版全部模型计划收窄；切换目标取消旧目标未发送的定时任务，保留独立手动任务和历史。
- 修复选择清空后被目录刷新填回、目标失效时静默换模型、旧计划保存后界面与实际范围不一致的问题。
- 拆分 SSE 限制：累计传输 32 MiB、单事件/单行 4 MiB、正文 2 MiB、生成 JSON 8 MiB；目录与分组查询仍为 2 MiB。仍要求有效正文和完整终态。
- 在线测试失败保留实际耗时、HTTP 状态、Token 用量、字节数及部分正文，不自动重试、换协议或换模型。
- 首次启用创作立即到期；忙碌时保留一个待执行周期，重复保存不重置时间，修改周期从保存时刻重新计算。
- 同步失败保留已存分组和原目录并刷新实际状态；同步按钮只调用当前分组。
- 公开展示与自动任务保持独立，后台显示作品不可见原因。绑定组查询是可选信息核对，不影响模型调用。

## 安装与升级

1. Windows 下载 `relaylab-windows-amd64-1.4.1.zip`；Linux 按 CPU 架构下载对应完整 `.tar.gz`。
2. 原生部署解压后复制 `config.example.yaml` 为私有 `config.yaml`，按说明初始化管理员。没有预置默认账号密码。
3. 宝塔 Docker 使用 [Docker 部署说明](../DOCKER.md) 中的源码或 Linux 完整包方案；HTTPS 域名填写 `RELAYLAB_PUBLIC_URL`。
4. v1.4.0 原生安装可使用后台在线升级；v1.2.2 及更早版本须按 [升级说明](../UPDATES.md) 先更新完整启动器和脚本。
5. 容器部署关闭应用内二进制自更新，使用重新构建镜像、重建容器升级。升级前备份持久化数据和主密钥。

## 附件与校验

固定 11 个附件：三个系统/架构的服务端和启动器共 6 个裸程序，3 个完整部署包，`manifest.json` 和 `SHA256SUMS`。

Manifest 记录完整 Commit、统一 UTC 构建时间、兼容范围及文件大小和 SHA-256。发布流程先创建草稿上传所有附件，重新下载验证后才发布为正式版和 latest。

Linux/macOS：

```sh
sha256sum -c SHA256SUMS
```

Windows：

```powershell
Get-FileHash .\relaylab-windows-amd64-1.4.1.zip -Algorithm SHA256
```

## 验证与已知限制

- 发布流程执行 Go 全量测试、go vet、前端测试、类型检查、生产构建、打包回归、Windows/Linux amd64 实际二进制升级恢复和 Linux 并发检查。
- Docker 使用独立 CI 构建与容器启动检查；Linux arm64 提供构建产物，未在宝塔 arm64 实机验证。
- 单模型调度、保存和响应处理使用本地协议夹具；桌面、短屏和手机布局另做浏览器验收。夹具结果不代表任意中转平台均已实测兼容。
- 连续 24 小时稳定性验收尚未完成；历史失败保留真实状态，原先未保存的在线测试不能补回。
- 每次测试只发送当前提示词，不携带历史会话。上游缓存、返回模型标识及取消后计费由提供方决定。
- 附件及镜像构建上下文不包含真实 Key、数据库、主密钥、日志、私有配置、GitHub Token 或代理密码。
