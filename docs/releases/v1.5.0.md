# Release v1.5.0 - 加密备份、S3 定时归档与恢复

## 发布信息

- 类型：正式功能版本；Tag `v1.5.0`，版本来源为根目录 `VERSION`。
- 发布时间以 GitHub Release 为准，日期与部署展示统一使用北京时间。
- 支持 Windows amd64、Linux amd64、Linux arm64。
- 数据库升级为 Schema 4，最低前向迁移版本为 Schema 1。
- launcher 协议保持 2，新增 `restore_v1` 能力。

## 新增功能

- 管理后台新增“备份与恢复”，包含记录、定时策略、S3 存储及恢复密钥设置。
- 全量 SQLite 一致性快照、age 公钥整包加密、本地保存及 S3/R2 兼容上传。
- 上传后回读校验、本地/远端状态分别展示、失败重试复用原包。
- 五段 Cron、明确时区、未来执行时间、普通保留、月度归档和永久保护。
- 云端目录分页扫描、加密包校验导入与源对象只读保护；迁移复核安全重绑定、显式活动存储与修订冲突处理。
- 原生 launcher 在线恢复预检、安全快照、文件替换事务、验证与失败回退。
- Docker 新数据卷恢复脚本及 Windows 加密备份/私钥文件恢复参数。

## 优化与修复

- 慢速备份导入使用专用读取期限，区分超时、大小超限与磁盘写入失败。
- 修复迁移目录复核、存储修订冲突、恢复附属文件阻断清理及 CLI 异常退出后的暂存回收。
- Docker 恢复先验证新卷，再停止旧服务；失败不会提前中断旧站点。
- 修复首次启动时 launcher 临时状态文件与空数据目录保护的竞态；仅识别托管启动产生的受限临时文件，无关目录和符号链接仍被拒绝。
- 系统设置采用独立页面，后台显示运行版本；容器仅检查新版本，安装通过镜像重建进行。
- 恢复进度在旧登录会话失效后继续可查，不重复提交恢复；云端导入记录删除不影响源对象。

## 恢复与安全边界

- 私钥由管理员离线保管，服务端不持久保存；备份整包加密，S3 凭据加密保存。
- 恢复校验包成员、哈希、数据库版本、完整性及后台、用户和存储凭据解密。
- 恢复后旧会话失效，旧任务队列不会重放；备份计划和清理先暂停并要求核对索引。
- 备份/恢复/升级使用跨进程操作协调，暂存放持久目录，避免 Docker 64 MiB `/tmp` 限制。
- 下载、恢复和解除保护要求管理员再次验证，普通用户没有备份接口权限。

## 安装与升级

1. 升级前保存当前数据库与 `master.key` 的受限安全快照。
2. 新安装使用对应系统/架构完整包；现有原生部署可以更新主程序，继续使用协议 2 launcher。
3. 旧 launcher 不具备在线恢复能力，需手动替换完整包中的新版 launcher 后重新启动。旧 CLI 默认 ZIP 格式继续兼容升级安全快照。
4. Schema 4 迁移后不能直接使用只支持 Schema 3 的旧程序运行当前数据库；回退历史数据须单独执行快照恢复。
5. Docker 重新构建对应版本镜像并保留现有卷；数据恢复使用新卷流程，不覆盖原卷。
6. 首次使用备份时先导出恢复私钥并验证；默认不会自动开启定时备份或月度归档。

完整配置与恢复步骤见 [备份与恢复说明](https://github.com/70548887/relay-api-monitor/blob/v1.5.0/docs/BACKUPS.md)。宝塔使用 [Docker 部署说明](https://github.com/70548887/relay-api-monitor/blob/v1.5.0/docs/DOCKER.md)。没有预置管理员密码或存储凭据。

第二轮边界修复与新增验证见 [修复记录](https://github.com/70548887/relay-api-monitor/blob/v1.5.0/docs/BACKUP-REPAIR.md)。

## 附件与校验

发布契约保持 11 个附件：6 个主程序/launcher 裸程序、3 个完整部署包、`manifest.json` 和 `SHA256SUMS`。完整包新增备份说明与 Docker 恢复脚本，不包含备份包、数据库、私钥、Token、日志或本机配置。

Manifest 记录完整 Commit、UTC 构建时间、Schema 4、最低迁移范围及附件大小/SHA-256。正式发布前通过构建与校验，草稿附件重新下载核对后再标记稳定版本。

- Windows：下载 `relaylab-windows-amd64-1.5.0.zip`。
- Linux x86_64：下载 `relaylab-linux-amd64-1.5.0.tar.gz`。
- Linux ARM64：下载 `relaylab-linux-arm64-1.5.0.tar.gz`。
- Linux/macOS 可运行 `sha256sum -c SHA256SUMS`；Windows 使用 `Get-FileHash` 与 `SHA256SUMS` 对照。
