# 备份模块第二轮审计修复

日期：2026-10-30。对应第二轮审计的六项问题及云端目录导入遗漏。本轮只使用隔离数据库、HTTP/S3 本地夹具和测试账号；未修改生产数据或发布 GitHub Release。

## 已修复

1. **慢速导入超时**：管理员鉴权、再次验证和并发准入通过后，备份 multipart 请求使用专用 30 分钟读期限；普通请求保留默认短期限。超时返回 408、体积超限 413、磁盘写入失败 507，避免统称超限。
2. **迁移路径冻结**：按当前实例目录中的文件名、原 SHA-256 和大小重新核对并绑定本地文件。拒绝篡改、链接及路径逃逸，不读取旧实例目录之外的数据。
3. **旧存储修订冲突**：活动存储显式保存，修订号在短事务内分配。复核只导入可信且被引用的旧修订，导入更高修订不会改变活动选择。异主密钥、无归属且不被当前库引用的目录保留为待核对警告，不阻塞新的有效数据集；当前实际引用而无法校验的副本仍冻结。
4. **Docker 提前停机**：先在新卷完成解密、恢复、数据校验与权限调整，失败保持旧服务运行；成功后才停止旧服务并提示显式切换卷。原卷不删除。
5. **附属文件阻断清理**：只把 32 位标识加 `.json` 识别为正式操作日志；`.submission.json` 采用独立校验/过期处理，不阻断其它明文预检目录的回收。损坏的正式恢复日志仍保守保护相关状态。
6. **CLI 崩溃暂存**：预检缓存增加操作系统独占锁、归属标记和下次运行的两小时过期清理。正常退出清理失败会报错。旧版无标记目录不自动删除，需管理员核对；CLI 没有常驻清理进程。

## 云端目录导入

后台可扫描当前存储前缀中的 `.zip.age`，分页列出待核对对象。候选 ID 为服务器生成的不透明标识，有效期一小时；客户端不能传入任意对象键或本机路径。

导入前再次验证管理员密码并输入对应私钥，固定对象 ETag，下载后执行 age、成员摘要、SQLite、主密钥及凭据校验。成功后仅新增受保护备份记录与本地加密副本，不恢复当前数据库。重复提交同一候选复用原记录；发布本地文件前保存校验摘要与源引用，避免崩溃产生无法核对的副本。

源对象保持只读。即使解除保护并删除导入记录，也只删除本机副本和索引，不删除源云对象。旧版明文 ZIP 使用普通导入预检入口。
